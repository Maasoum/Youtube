# فونت پِیدا (Peyda)

فایل‌های فونت در `src/index.css` با `@font-face` معرفی شده‌اند، اما فایل‌ها
عمداً در این نسخه قرار داده نشده‌اند. برای فعال شدن فونت برند، این دو فایل را
در همین پوشه قرار دهید:

- `PeydaWeb-Regular.woff2` — وزن ۴۰۰
- `PeydaWeb-Bold.woff2` — وزن ۷۰۰

تا زمانی که فایل‌ها اضافه نشده‌اند، فالبک `Tahoma, system-ui` استفاده می‌شود و
چیدمان سایت به‌درستی نمایش داده می‌شود. فقط دو وزن ۴۰۰ و ۷۰۰ در پروژه استفاده
می‌شود و `font-synthesis: none` جلوی جعل وزن را می‌گیرد.
